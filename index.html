Panduan Membuat Web Data Buku Perpustakaan dengan Laravel

Dokumen ini menjelaskan secara lengkap implementasi aplikasi pengelola data buku perpustakaan menggunakan framework **Laravel**, arsitektur **Model-View-Controller (MVC)**, resource routing, validasi input, serta fungsi **CRUD** (*Create, Read, Update, Delete*).

1

Fitur Aplikasi

Daftar Buku

Melihat daftar seluruh buku dalam format tabel interaktif.

Tambah Buku Baru

Form untuk menambahkan data koleksi buku baru ke database.

Detail Informasi

Melihat rincian lengkap atribut dari suatu buku spesifik.

Ubah & Edit Data

Memperbarui informasi buku yang sudah ada.

Hapus Data

Menghapus data buku disertai dialog konfirmasi keamanan.

Validasi & Alert

Validasi data ketat dan pesan notifikasi sukses/gagal.

2

Persiapan Lingkungan Pengembangan

Proyek ini menggunakan **Laravel 13** dan memerlukan **PHP 8.3** atau lebih baru. Pastikan PHP, Composer, dan Node.js/npm telah terpasang di komputer Anda.

PowerShell / Terminal - Periksa Versi 
php -v
composer -V
node -v
npm -v

Jika memulai dari proyek Laravel yang sudah ada:

Inisialisasi Project 
cd C:\laragon\www\cobaUPSM
composer install
Copy-Item .env.example .env
php artisan key:generate
Peringatan Keamanan: Jangan menyalin atau mengunggah isi berkas .env ke dokumentasi atau repositori publik karena berkas tersebut menyimpan kredensial database dan kunci rahasia aplikasi.

Konfigurasi Database (SQLite)

Proyek ini secara default memakai SQLite. Buat berkas database jika belum ada:

Buat File SQLite 
New-Item -ItemType File -Force database\database.sqlite

Pastikan baris berikut pada berkas .env terkonfigurasi:

.env 
DB_CONNECTION=sqlite
DB_DATABASE=database/database.sqlite
3

Membuat Struktur Komponen dengan Artisan

Gunakan CLI `php artisan` untuk membuat kerangka file Model, Controller, dan Migration:

Artisan Commands 
php artisan make:model Book -m
php artisan make:controller BookController --resource --model=Book

Catatan Perintah Artisan:

    make:model Book -m: Membuat Model Book sekaligus file Migration tabel database. make:controller BookController --resource --model=Book: Membuat Resource Controller lengkap dengan fungsi CRUD dan implicit Route Model Binding.

5.2 Model — app/Models/Book.php

Model Eloquent mewakili tabel books. Properti $fillable mengatur izin Mass Assignment.

Book.php 
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class Book extends Model
{
    use HasFactory;

    /**
     * The attributes that are mass assignable.
     *
     * @var array<int, string>
     */
    protected $fillable = [
        'kode_buku',
        'judul',
        'penulis',
        'penerbit',
        'tahun_terbit',
        'stok',
    ];
}

5.3 Controller — app/Http/Controllers/BookController.php

Controller menangani request HTTP, fungsi validasi form, serta interaksi dengan database melalui model Eloquent.

BookController.php 
<?php

namespace App\Http\Controllers;

use App\Models\Book;
use Illuminate\Http\Request;
use Illuminate\Validation\Rule;

class BookController extends Controller
{
    /**
     * Display a listing of the resource.
     */
    public function index()
    {
        $books = Book::latest()->get();
        return view('books.index', compact('books'));
    }

    /**
     * Show the form for creating a new resource.
     */
    public function create()
    {
        return view('books.create');
    }

    /**
     * Store a newly created resource in storage.
     */
    public function store(Request $request)
    {
        $validated = $request->validate([
            'kode_buku'    => ['required', 'string', 'unique:books,kode_buku'],
            'judul'        => ['required', 'string'],
            'penulis'      => ['required', 'string'],
            'penerbit'     => ['required', 'string'],
            'tahun_terbit' => ['required', 'integer', 'digits:4', 'min:1900', 'max:' . date('Y')],
            'stok'         => ['required', 'integer', 'min:0'],
        ], [
            'kode_buku.required'    => 'Kode buku wajib diisi.',
            'kode_buku.unique'      => 'Kode buku sudah terdaftar.',
            'judul.required'        => 'Judul buku wajib diisi.',
            'penulis.required'      => 'Penulis wajib diisi.',
            'penerbit.required'     => 'Penerbit wajib diisi.',
            'tahun_terbit.required' => 'Tahun terbit wajib diisi.',
            'tahun_terbit.integer'  => 'Tahun terbit harus berupa angka.',
            'tahun_terbit.digits'   => 'Tahun terbit harus 4 digit angka.',
            'tahun_terbit.min'      => 'Tahun terbit minimal tahun 1900.',
            'tahun_terbit.max'      => 'Tahun terbit tidak boleh melebihi tahun berjalan.',
            'stok.required'         => 'Stok wajib diisi.',
            'stok.integer'          => 'Stok harus berupa bilangan bulat.',
            'stok.min'              => 'Stok minimal 0.',
        ]);

        Book::create($validated);

        return redirect()->route('books.index')->with('success', 'Data buku berhasil ditambahkan!');
    }

    /**
     * Display the specified resource.
     */
    public function show(Book $book)
    {
        return view('books.show', compact('book'));
    }

    /**
     * Show the form for editing the specified resource.
     */
    public function edit(Book $book)
    {
        return view('books.edit', compact('book'));
    }

    /**
     * Update the specified resource in storage.
     */
    public function update(Request $request, Book $book)
    {
        $validated = $request->validate([
            'kode_buku'    => ['required', 'string', Rule::unique('books', 'kode_buku')->ignore($book->id)],
            'judul'        => ['required', 'string'],
            'penulis'      => ['required', 'string'],
            'penerbit'     => ['required', 'string'],
            'tahun_terbit' => ['required', 'integer', 'digits:4', 'min:1900', 'max:' . date('Y')],
            'stok'         => ['required', 'integer', 'min:0'],
        ], [
            'kode_buku.required'    => 'Kode buku wajib diisi.',
            'kode_buku.unique'      => 'Kode buku sudah digunakan oleh buku lain.',
            'judul.required'        => 'Judul buku wajib diisi.',
            'penulis.required'      => 'Penulis wajib diisi.',
            'penerbit.required'     => 'Penerbit wajib diisi.',
            'tahun_terbit.required' => 'Tahun terbit wajib diisi.',
            'tahun_terbit.integer'  => 'Tahun terbit harus berupa angka.',
            'tahun_terbit.digits'   => 'Tahun terbit harus 4 digit angka.',
            'tahun_terbit.min'      => 'Tahun terbit minimal tahun 1900.',
            'tahun_terbit.max'      => 'Tahun terbit tidak boleh melebihi tahun berjalan.',
            'stok.required'         => 'Stok wajib diisi.',
            'stok.integer'          => 'Stok harus berupa bilangan bulat.',
            'stok.min'              => 'Stok minimal 0.',
        ]);

        $book->update($validated);

        return redirect()->route('books.index')->with('success', 'Data buku berhasil diperbarui!');
    }

    /**
     * Remove the specified resource from storage.
     */
    public function destroy(Book $book)
    {
        $book->delete();

        return redirect()->route('books.index')->with('success', 'Data buku berhasil dihapus!');
    }
}

Menjalankan Aplikasi

Jalankan urutan perintah berikut pada terminal proyek:

Perintah Eksekusi 
# 1. Jalankan migrasi database
php artisan migrate

# 2. Periksa daftar route yang terdaftar
php artisan route:list --path=books

# 3. Jalankan server lokal Laravel
php artisan serve

Buka browser dan kunjungi alamat: http://127.0.0.1:8000

Tips Migration Fresh: Jika pernah menjalankan migration kosongan sebelumnya, perbarui struktur database dengan:

php artisan migrate:fresh

Peringatan: `migrate:fresh` akan menghapus seluruh data pada database lokal Anda.

Penjelasan Alur Request MVC

1

Browser / User

Mengirim request URL (Contoh: `GET /books`).

2

Routing (web.php)

Meneruskan request ke Controller yang sesuai.

3

Controller

Menjalankan logika, validasi, & memanggil Model.

4

Model (Book)

Membaca / menulis data pada database SQLite.

5

View (Blade)

Merender tampilan HTML dan menampilkan ke user.

8

Skenario Pengujian Aplikasi

Skenario A: Membuka Daftar Buku

Akses /, pastikan redirect otomatis ke /books dan tabel muncul.

Skenario B: Menambah Buku (Input Valid)

Isi data: Kode=BK-001, Judul=Belajar Laravel, Penulis=Ayu Pratama, Penerbit=Pustaka Sekolah, Tahun=2024, Stok=5. Pastikan data berhasil tersimpan.

Skenario C: Memeriksa Validasi Form

Kirim form kosong, atau gunakan Kode Buku ganda (`BK-001`). Pastikan pesan kesalahan validasi muncul.

Skenario D & E: Detail & Edit Buku

Uji tombol detail untuk melihat rincian. Uji tombol edit dan pastikan data lama otomatis terisi pada form.

Skenario F: Hapus Buku

Klik tombol hapus. Pastikan popup dialog konfirmasi muncul sebelum data dihapus dari database.
